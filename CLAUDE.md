# Project Instructions

## Package Manager

This project uses **pnpm** as the package manager.

- Install dependencies: `pnpm install`
- Add a package: `pnpm add <package>`
- Add a dev dependency: `pnpm add -D <package>`
- Run scripts: `pnpm <script-name>`

## Design System Reference

Before creating or changing UI components, read `docs/design.md`.
It documents Figma-derived component states, shared className patterns, and commonization candidates such as search inputs, dropdowns, select fields, calendars, pagination, modal action buttons, filter tags, and table primitives.
